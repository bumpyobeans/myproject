# 네이버 광고 계정 정리 (5개 → 사업자별 3개)

> 목표: 담당자가 헷갈리지 않게 **계정마다 역할 하나**, 안 쓰는 계정은 잠그고, 지난 대행사 권한은 없앤다.
> 원칙: **사업자번호 1개 = 광고 계정 1개** (네이버 원칙: 업체 사업자 정보로 만든 계정이 직접 광고).

|---|---|---|---|

> 원칙 보완: **광고가 가리키는 곳(온라인몰·매장)의 사업자 = 광고 계정의 사업자.** 별내점 반려도 이 불일치 때문. 광고비 세금계산서도 계정 사업자 앞으로 나오므로, 온라인몰 광고비는 팩토리, 매장 광고비는 법인으로 나뉘는 게 회계상 깔끔.

## 1-0. 사업자 이력 (2026-10-29 대표 확인)

- 처음: 구리갈매점·범표원두팩토리 모두 **배우자 명의 개인사업자**
- 사업 확장: **구리갈매점을 대표 본인 명의 법인으로 이관** → 별내점은 법인 지점
- 지금: 네이버 아이디 1개가 스마트플레이스 업체 3개(구리갈매점·별내점·범표원두팩토리)와 서로 다른 사업자를 함께 관리
- 그래서 생길 수 있는 문제: 오래된 광고 계정·스마트플레이스 정보가 **이관 전 개인사업자 번호**로 남아 있을 수 있음

## 1-1. 범표_2026 사업자번호 확인 후 결정

> **확인 결과 (2026-10-29): 범표_2026 = 범표원두팩토리 사업자 (677-24-*****, 84899와 같은 번호). 운영 유형 "대행권 이관".** → 아래 표 첫 줄로 확정.
> - 범표_2026 = **온라인몰 메인 계정** (쇼핑검색·브랜드 방어, 무상 77만원은 여기서 소진)
> - 84899 = **같은 사업자 중복 빈 계정** → 잔액·쿠폰 0 확인 후 삭제
> - 구리갈매점 지역소상공인광고(지금 범표_2026에서 운영) = 법인 매장 광고가 팩토리 계정에 있는 상태 → **법인 계정으로 이동** (세금계산서도 법인으로)
> - 별내점이 범표_2026에서 반려된 이유: 법인 지점 vs 팩토리 개인사업자 = **완전히 다른 사업자** → 서류로 풀 수 없음. 범표_2026 쪽 재검토 요청 중단.

범표_2026은 2023년 쿠폰 이력이 있는 **오래된 계정**(이름만 2026) → 이관 전 정보일 가능성 있음.

| 범표_2026의 사업자가… | 범표_2026 (무상 77만원) | 84899 (팩토리, 빈 계정) | 구리갈매점 매장 광고 |

## 2. 계정별 점검 (계정 하나당 5분)

오른쪽 위 계정 이름 → 계정 전환 후, 아래 5가지를 표에 채운다.

1. **광고 계정 관리 → 광고 계정 정보**: 계정 ID, 업체명, **사업자등록번호** (본점/별내점)
2. **결제 관리 → 비즈머니 관리**: 유상 / 무상 잔액
3. **결제 관리 → 비즈쿠폰 관리**: 사용 안 한 쿠폰 있는지
4. **전체 캠페인**: ON 상태 캠페인, 최근 30일 비용
5. **광고 계정 관리 → 권한 관리**: 권한 가진 사람 (**예전 대행사가 남아 있는지**)

## 3. 정리 순서

### ① 범표_2026 — 본점 메인 계정
- [ ] 별내점 비즈채널 재검토 요청은 **취소/중단** (범표_2026은 팩토리 사업자라 법인 지점 광고 불가)
- [ ] 구리갈매점 지역소상공인광고(VIP카드 혜택받기)는 법인 계정이 준비되면 그쪽으로 옮기고 여기선 OFF
- [ ] "대행권 이관" = 예전 대행사가 운영하던 계정 → 권한 관리에서 대행사 권한 남아 있는지 꼭 확인
- [ ] 아직 못 찾은 캠페인 확인: 전체 캠페인 → 총비용 순 정렬 (주 약 3만원이 어디서 나가는지)
- [ ] 권한 관리: 예전 대행사 권한 **삭제**, 담당 직원 **추가** (책임자 말고 운영 권한)
- [ ] 알림 관리: 검수 반려·잔액 부족 알림을 담당 직원에게도

### ② 구리갈매점 ADVoost (2634933) — 둘 중 하나
- 범표_2026 → 플레이스 → "+ 새 광고그룹"에 **플레이스 검색 유형이 있으면** → 범표_2026에서 무상 잔액으로 진행, **ADVoost는 "광고 사용" OFF** (충전 안 함)
- **없으면** → 이 계정에 9만원 충전, 2주 테스트 (하루 3,000원)
- [ ] 스마트플레이스 → 마케팅 → 쿠폰에 VIP카드 혜택 등록 (ADVoost 소재에 노출)

### ③ 별내점 ADVoost (2628391) — 별내점 전용 계정으로
- [ ] 사업자번호가 **별내점 번호인지** 확인
- [ ] 맞으면: 계정 업체명 "범표원두 별내하나로마트점" → **"범표원두 별내점"**으로 맞춤 (광고 계정 정보에서 수정, 안 되면 고객센터) → 비즈채널 재검토 요청
- [ ] 비즈머니 충전 (별내점 예산만큼)
- [ ] 아니면(본점 번호면): 고객센터에 "동일 법인 지점" 서류(본점·별내점 사업자등록증)로 처리 문의

### ④-1 범표원두 (84899) — 범표원두팩토리 = 온라인몰 사업자 계정 (삭제 금지 보류)
- [ ] **범표_2026의 사업자번호부터 확인** → 위 1-1 표로 이 계정의 운명 결정
- [x] 전체 캠페인: **등록된 캠페인 없음** (2026-10-29 확인) — 빨간 배너는 잔액 0이라 뜨는 일반 안내
- [ ] 비즈머니·비즈쿠폰 잔액 기록

### ④-2 팩토리 사업자 중복 계정 2개 삭제 (60711, 84899)

같은 사업자(범표원두팩토리)로 계정이 3개 → **범표_2026만 남긴다** (무상 77만원·운영 중 캠페인 있음).

삭제 전 계정마다:
- [ ] 전체 캠페인 없음/OFF 확인 (84899는 없음 확인, 60711 확인 필요)
- [ ] 비즈머니 유상·무상 0원 확인 (유상 남으면 환불 먼저)
- [ ] 비즈쿠폰 관리: 미사용 쿠폰 없는지
- [ ] **세금계산서·소진 내역 다운로드** (결제 관리 → 세금계산서 / 기간별 내역 → 다운로드) — 삭제하면 과거 내역 확인이 어려울 수 있음, 세무 보관용
- [ ] 광고 계정 정보 → **계정 삭제**

### ④ 범표원두 (2) 및 미사용 계정 잠금
- [ ] 무엇으로 만든 계정인지 확인 (예전 대행사, 예전 사업자 등)
- [ ] **비즈머니 잔액이 있으면**: 유상 → 환불 신청 / 무상 → 해당 계정에서 소진 계획 또는 고객센터 문의 (계정 간 이전 불가)
- [ ] 미사용 쿠폰 있으면 기록
- [ ] 모든 캠페인 OFF, 권한자 정리
- [ ] 계정명을 바꿀 수 있으면 앞에 **"미사용_"** 붙이기
- [ ] **삭제는 마지막에**, 잔액·세금계산서 정리 끝난 뒤
