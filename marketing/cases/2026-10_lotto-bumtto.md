## 1. 배경

- 방영 중인 인기 드라마 **「로또 1등도 출근한다」**를 소재로 삼음.
- "명당에서 산 진짜 로또"를 혜택으로 → 원두 1kg 이상 구매를 유도하는 것이 목표.

## 5. 성공 요인 (도달·신규 유입)

1. **모두가 아는 이슈에 올라탔다.** 방영 중인 드라마 제목을 그대로 훅으로 → 브랜드를 모르는 사람도 멈춰서 봄.
2. **"진짜로 했다"는 체험.** 직원이 실제로 명당에 뛰어가 로또를 사는 장면 → 연출 광고가 아니라 재미있는 이야기라 공유(15)·댓글(16)이 붙음.
3. **커피 얘기를 안 했다.** 범표 티셔츠·캐릭터만 노출하고 제품 설명 없이 재미로 승부 → 광고 거부감 없이 브랜드 인지.
4. **광고가 클릭을 만들었다.** 도달 대비 웹사이트 방문 14.4% — 이 소재는 클릭을 부르는 힘이 강함.

## 6. 왜 1kg 구매로는 안 이어졌나 (가설)

- [ ] **혜택 대비 조건이 무거움.** 로또 1장(체감가치 수천 원)을 받으려고 평소보다 많은 1kg을 사기는 어렵다. 재미는 있지만 "지금 사야 할 이유"로는 약함.
- [ ] **기간이 짧고 이미 원두가 있는 고객.** 최근 6개월 구매자는 집에 원두가 남아있을 가능성 → 2.5일 안에 재구매 타이밍이 안 맞음.
- [ ] **광고 910명 방문 → 구매 0에 가까움.** 신규 방문자에게 처음부터 1kg은 부담. 착지 페이지가 이벤트 안내 / 소용량 체험으로 이어졌는지 확인 필요.
- [ ] **"재미"와 "구매"가 분리됨.** 릴스는 웃겼지만 영상 안에 이벤트 조건·구매 경로 안내가 약했을 수 있음.

## 7. 다음에 바꿀 것

- [ ] 화제 콘텐츠의 목표를 **"신규 유입·팔로우"로 따로 잡고**, 구매 유도는 별도 혜택으로 분리해 판단.
- [ ] 이벤트 혜택은 문턱을 낮추거나(예: 500g 이상 / 드립백 포함) "구매 고객 전원 로또 1장 + 1kg은 3장"처럼 단계형으로.
- [ ] 매장 신규 고객에게 **"어떻게 알고 오셨어요?"** 확인 → 릴스 효과를 숫자로 기록.
- [ ] 광고 착지: 신규 방문자는 소용량(드립백·500g)·이벤트 안내 페이지로.
- [ ] 영상 마지막 3초에 이벤트 조건과 기간 자막 추가.
- [ ] 경품(복권 등) 제공 시 관련 규정 사전 확인.
