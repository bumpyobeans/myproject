## 1. 배경

- 범표원두 드립백커피(조선호랑이 / 디카페인호랑이)가 **올리브영 글로벌몰** 입점.
- 입점 후 외국인 리뷰가 쌓이기 시작함 (국내 거주 외국인 + 해외 구매자).
  - 글로벌몰 상품: *bumpyobeans Tiger Drip Bag Coffee 70g* — 평점 5.0, 리뷰 7건, US$11.51~
  - 대표 리뷰 (Joseon Tiger 70g, ★5, 맛 ★5 / 패키지 ★5):
    > "Giving this as a gift. It looks expensive and classy and fancy that it would be perfect to give for coffee lovers."

## 4. 성공 요인 (왜 반응이 좋았나)

1. **제3자 인정이 메시지의 주어.** "우리 커피 맛있어요"가 아니라 *올리브영*이 입점시켰고 *외국인*이 칭찬했다 → 신뢰도가 자동으로 붙음.
2. **리뷰 원문을 그대로 보여줌.** 캡처 + 자막 + 화살표로 "진짜 리뷰"임을 증명. 꾸민 카피보다 설득력 높음.
3. **"선물"이라는 구매 이유를 리뷰가 대신 말해줌.** 패키지 고급감 → 선물 수요로 연결되는 문장을 고객 입으로 확보.
4. **원소스 멀티유즈.** 영상 1개로 인스타·스레드·네이버 클립 3채널 커버 → 제작비 거의 0으로 노출 확대.
5. **해외 화제 → 국내 구매로 전환 장치.** 메시지에서 "세계에서도 인기" 자부심 + 기간 한정 쿠폰으로 국내 몰 구매 유도.
6. **기존 고객에게 "내가 아는 브랜드가 세계에서 인정받았다"는 뉴스.** 라운지 가입 고객이라 이미 신뢰가 있는 상태 → 읽음률 17.3%, 읽은 고객의 59%가 클릭. 이슈와 맞아떨어진 메시지의 전형.

### 핵심 발견: 메시지는 "직접 판매"가 아니라 "구매 계기"를 만든다

- 메시지 링크 경유 구매는 1건(1.52%)뿐이지만, **온라인 스토어에서 드립백 30개입이 주말 이틀간 12건 주문됐다.** 평소엔 한 달에 1건 나오는 상품이다.
- 고객은 메시지를 보고 → 관심이 생긴 뒤 → 메시지 링크가 아닌 평소 구매 경로(스토어 직접 검색·즐겨찾기 등)로 들어와 **대용량**으로 구매.
- 클릭 고객 39명 중 최대 12명이 30개입을 샀다고 보면, 클릭 고객의 상당수가 실제 구매까지 갔을 가능성이 크다 (메시지 경유 여부는 미확인).
- → 메시지 성과를 **링크 전환율만으로 판단하면 과소평가**된다. 발송 후 7일간 해당 제품의 전 채널 판매를 같이 본다 (README 룰 6).

## 5. 아쉬운 점 / 다음에 바꿀 것

- [ ] 쿠폰 문턱(10만원 이상)이 높아 링크 직접 구매가 적었을 수 있음 → 다음엔 낮은 문턱(예: 3만원) 쿠폰과 비교. 단, 30개입 주문이 주말에만 12건 나온 것처럼 객단가 높은 구매가 나왔으므로 무작정 낮추기보다 "30개입 구매 시 쿠폰"처럼 대용량 유도형도 테스트.
- [ ] 30개입 주문이 메시지 때문인지 확인하는 장치가 없었음 → 다음엔 메시지 전용 쿠폰코드 / 링크에 유입 추적 파라미터 / 주문자가 메시지 수신 고객인지 대조.
- [ ] 메시지 링크가 30개입 상품으로 바로 가지 않았다면 링크 랜딩 확인 — 고객이 실제로 산 상품으로 바로 연결되게.
- [ ] 쿠폰 사용기간 1일 → 긴급성은 높지만 놓치는 고객도 있음. 클릭 대비 사용률 확인 후 판단.
- [ ] 채널별 업로드 시간·캡션 차이를 기록하지 않아 비교가 어려움 → 템플릿에 항목 추가함.
- [ ] 리뷰 작성자 동의/표기 정책 확인 (리뷰 캡처 시 닉네임 가림 처리 기준 통일).
