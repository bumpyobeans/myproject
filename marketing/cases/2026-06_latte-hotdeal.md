## 3. 성공 요인 (가설 — 행사 내용 확인 후 보완)

1. **가격이 가장 강한 신규 유입 장치.** 브랜드를 몰라도 "싸게 살 수 있는 맛있는 라떼"면 들어온다 → 신규 고객 +58%.
2. **한 번 들어온 사람이 "찜·알림"을 남겼다.** 관심·알림 증가 2배 → 핫딜이 끝나도 다음 메시지를 받을 수 있는 고객 풀이 커짐 (알림 12,557명의 출발점).
3. **진입 장벽 낮은 상품.** 원두보다 라떼가 처음 사기 쉬운 상품 → 첫 구매용으로 적합.

## 4. 남은 질문 / 다음에 바꿀 것

- [ ] **재구매로 이어졌나?** 7월 기존 고객 287명(평소 283명)으로 거의 그대로 → 6월 신규 253명 대부분이 재구매하지 않았을 가능성. 6월 신규 고객의 7~9월 재구매율 확인 필요.
- [ ] **환불 37건(최다)** — 핫딜 고객의 환불 사유 확인 (배송·기대 차이 등).
- [ ] **"범표라떼" 검색 수요가 아직 남아있다.** 최근 30일(9/19~10/18) "범표라떼" 검색 방문 19명, 결제 0 → 핫딜로 이름을 알게 된 고객이 다시 찾는 중일 수 있음. 검색 시 상품이 바로 나오는지, 판매 중인지 확인.
- [ ] 다음 핫딜엔 **재구매 장치**를 같이: 핫딜 구매자에게 라운지 가입 유도 + 2주 후 원두/드립백 쿠폰 메시지.
