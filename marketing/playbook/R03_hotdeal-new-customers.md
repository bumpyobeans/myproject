# R03. 대표 상품 핫딜로 신규 고객 대량 유입

- 상태: **후보** (1회, 신규 유입 성공 / 재구매 연결 미확인)
- 근거 사례: [2026-06 범표라떼 핫딜](../cases/2026-06_latte-hotdeal.md)

## 한 줄 요약

**처음 사기 쉬운 대표 상품(범표라떼)을 핫딜로 열어 신규 고객과 찜·알림 고객을 크게 늘리고, 2주 안에 재구매 메시지로 단골로 바꾼다.**

> 신규 유입은 핫딜이 가장 강하다 (신규 +58%). 하지만 핫딜만으로 끝나면 할인 고객만 남는다 → **STEP 4(재구매 연결)가 이 루틴의 핵심.**

## 언제 돌리나

- [ ] 신규 고객이 평소(월 160명)보다 줄어드는 달
- [ ] 비수기 진입 전 고객 풀(찜·알림)을 늘려두고 싶을 때
- [ ] 재고 회전이 필요한 대표 상품이 있을 때

## 실행 순서

### STEP 1. 상품·가격 정하기
- [ ] 처음 사기 쉬운 상품 (객단가 낮고 맛 설명이 쉬운 것 — 라떼, 드립백)
- [ ] 할인율·수량·기간, 마진 확인
- [ ] 진행 채널: ____ (1회차 채널 기록 후 채우기)

### STEP 2. 상세페이지 준비
- [ ] 상품 상세에 **"찜하기·알림받기 하면 다음 핫딜 먼저 알려드려요"** 문구
- [ ] 라운지 가입 혜택 안내
- [ ] 다른 상품(원두·드립백)으로 가는 연결 배너

### STEP 3. 핫딜 진행
- [ ] 기간 중 재고·배송 점검 (1회차 환불 37건 최다 → 원인 확인 후 대비)

### STEP 4. 재구매 연결 (핫딜 종료 후 2주 내)
- [ ] 핫딜 구매자에게 메시지: "라떼 맛있게 드셨나요?" + 원두/드립백 첫 구매 쿠폰
- [ ] 1개월 후 핫딜 상품 재구매 알림 (정가 or 소폭 할인)

### STEP 5. 측정
- [ ] 행사 달 신규 고객 (평소 160명) / 관심·알림 증가 (평소 각 약 100명)
- [ ] **다음 달·다다음 달 기존 고객 수** (평소 283명) — 핫딜 고객이 남았는지
- [ ] 핫딜 구매자 재구매율 (1·2·3개월)
- [ ] 환불률 (평소 5%)
- [ ] 이후 "범표라떼" 검색 방문 추이

## 성공 기준

| 지표 | 성공 |
|---|---|
| 행사 달 신규 고객 | 평소 160명 대비 +40% 이상 (1회차 +58%) |
| 관심·알림 증가 | 평소의 2배 (1회차 2.1~2.2배) |
| 다음 달 기존 고객 | 평소 283명보다 증가 (1회차 287명 → 거의 변화 없음, **미달**) |
| 환불률 | 평소 5% 이하 유지 (1회차 5.8%) |
