# R01. 외부 인정(입점·리뷰) 원소스 멀티채널 확산

- 상태: **후보** (성공 1회 — 1회 더 기준선 초과 시 정식 루틴)
- 근거 사례: [2026-10 올리브영 글로벌몰 입점](../cases/2026-10_oliveyoung-global.md)

## 한 줄 요약

**외부에서 인정받은 순간(입점·수상·좋은 리뷰·언론 노출)이 생기면, 증거를 캡처해 영상 1개로 만들고 → 인스타·스레드·네이버 클립에 동시 배포 → 마케팅 메시지 + 기간 한정 쿠폰으로 구매까지 연결한다.**

## 언제 돌리나 (트리거)

아래 중 하나가 생기면 바로 시작한다. 타이밍이 생명이므로 **트리거 발생 후 3일 안에 1차 콘텐츠 업로드**.

- [ ] 신규 판매처 입점 (올리브영, 백화점, 해외몰, 편집숍 등)
- [ ] 외국인/해외 구매자 리뷰 3건 이상 누적
- [ ] 별점 5점 + 구체적인 칭찬 문장이 있는 리뷰 (선물, 패키지, 향, 맛 등)
- [ ] 수상, 언론·인플루언서 언급, 협업 제안

## 실행 순서

### STEP 1. 증거 수집 (D+0, 30분)

- [ ] 입점 페이지 / 리뷰 화면 캡처 (상품명, 별점, 리뷰 수, 가격 보이게)
- [ ] 리뷰 중 **"인용할 한 문장"** 고르기 — 기준: 구매 이유가 드러나는 문장 (예: "선물하기 완벽")
- [ ] 리뷰 작성자 닉네임 가림 처리
- [ ] 실물 제품 촬영 (손에 들고 찍기 / 매장·진열 배경)

### STEP 2. 영상 1개 제작 (D+1, 1~2시간)

릴스 기준 9:16, 10~20초. 구성:

| 구간 | 화면 | 자막 |
|---|---|---|
| 0~2초 (훅) | 실물 제품 클로즈업 또는 입점 로고 | 인용 문장 크게 / "OO 입점했습니다!" |
| 2~10초 | 리뷰·상품페이지 캡처 + 강조 화살표 | 리뷰 원문 (외국어면 원문 + 한글 번역) |
| 10~15초 | 제품 사용 장면 (드립 내리는 모습 등) | 브랜드 슬로건 "Unusual beans, Unusual coffee." |
| 마지막 | 구매 경로 | "프로필 링크 / 올리브영 글로벌몰 검색" |

- [ ] 입점 공지용 정지 이미지 1장도 같이 제작 (메시지·스레드 썸네일 재사용)

### STEP 3. 멀티채널 동시 배포 (D+2, 1시간)

같은 영상, **캡션만 채널에 맞게** 바꾼다.

| 채널 | 캡션 톤 | 체크 |
|---|---|---|
| 인스타그램 릴스 | 이모지 + 짧은 스토리, 해시태그 5~10개, 상품 태그 | [ ] |
| 스레드 | 대화체, 질문으로 끝내기 ("여러분은 커피 선물 뭐 주세요?") | [ ] |
| 네이버 클립 | 검색 키워드 앞에 배치 (드립백커피, 커피선물, 올리브영) | [ ] |

- [ ] 3채널 업로드 시간 기록 (사례 파일에)
- [ ] 업로드 후 1시간 내 댓글 응대

### STEP 4. 마케팅 메시지 발송 (D+2~D+3)

SNS 반응이 붙은 다음 날 발송해 화제성을 이어받는다.

- [ ] 제목 공식: `🐯 [제품명], [외부 인정 포인트]!` — 예: "조선호랑이, 세계에서도 인기짱!"
- [ ] 본문 공식: ① 자부심(어디서 인정받았나) → ② 기념 혜택 → ③ 지금 행동
- [ ] 이미지: STEP 2 정지 이미지 재사용
- [ ] 버튼 2개: 해당 제품 + 시즌 상품 (교차판매)
- [ ] 쿠폰: 기념 할인 쿠폰 (조건·기간은 A/B 테스트 대상 — 아래 참고)
- [ ] 대상: 기존 고객(라운지 가입 고객) — 이미 브랜드를 아는 고객에게 "우리 브랜드 소식"으로 전달할 때 반응이 좋음
- [ ] **매장에 미리 공유**: 발송 일시·내용·쿠폰을 매장에 알리고, 해당 제품(특히 대용량) 재고 확보 + "메시지 보고 오셨나요?" 확인

### STEP 5. 측정 & 기록 (D+7)

- [ ] 채널별 지표를 `cases/` 사례 파일에 기입, 기준선 대비 배수 계산
- [ ] 입점처 리뷰 수 / 판매 변화 확인
- [ ] **간접 전환**: 발송 후 7일간 매장·스마트스토어 등에서 해당 제품 판매(건수·금액·대용량 비중)를 직전 같은 기간과 비교
- [ ] 성공 요인 3줄, 다음에 바꿀 것 정리 → 이 루틴 업데이트

## 성공 기준 (기준선 대비)

| 지표 | 성공 |
|---|---|
| 릴스 조회수 | 기준선 1.5배 이상 |
| 저장 + 공유 | 기준선 2배 이상 (선물·추천 의도 신호) |
| 메시지 읽음률 (읽은 고객 ÷ 발송) | **15% 이상** (1회차 실적 17.3%) |
| 메시지 클릭률 (클릭 ÷ 읽은 고객) | **15% 이상** (1회차 실적 59.1%) |
| 직접 전환 (메시지 링크 구매) | 참고 지표 — 낮아도 실패로 보지 않음 (1회차 1.52%) |
| 간접 전환 (매장·타 채널 해당 제품 판매) | D+0~D+7 판매가 직전 같은 기간 대비 증가 (1회차: 매장 드립백 30개입 주문 연속) |

## 다음 실행 때 테스트할 것

- 쿠폰 문턱: 10만원 이상 vs 3만원 이상 vs "30개입 구매 시" (대용량 유도형)
- 매장 연동: 메시지 전용 쿠폰코드를 매장에서도 쓸 수 있게 해 간접 전환을 숫자로 잡기
- 쿠폰 기간: 1일 vs 3일
- 훅: 리뷰 인용 문장 vs 입점 로고
- 메시지 발송 타이밍: 영상 업로드 당일 vs 다음 날

## 응용 예시

- 해외몰 리뷰 → "외국인이 고른 한국 커피" 시리즈로 정기화 (리뷰 3건 쌓일 때마다)
- 선물 리뷰 → 명절·연말 선물 시즌 메시지 소재로 재활용
- 매장 입점 → "OO에서 만나보세요" + 매장 방문 인증 이벤트
