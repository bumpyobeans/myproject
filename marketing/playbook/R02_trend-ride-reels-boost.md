# R02. 화제 이슈 편승 체험 릴스 + 광고 부스트

- 상태: **후보** (도달·신규 유입 성공 1회 / 구매 전환은 미달)
- 근거 사례: [2026-10 범또(BUMTTO) 로또 이벤트](../cases/2026-10_lotto-bumtto.md)

## 한 줄 요약

**지금 모두가 아는 이슈(드라마·예능·시즌 이벤트)를 범표 직원이 "진짜로 해보는" 짧은 체험 영상으로 만들고, 오가닉 반응이 붙으면 광고로 3일 밀어 신규 고객을 데려온다.**

> 이 루틴의 목표는 **도달·팔로우·신규 방문**이다. 기존 고객 구매는 R01이나 별도 혜택 메시지로 따로 잡는다.

## 언제 돌리나 (트리거)

- [ ] 방영 중인 인기 드라마·예능에 커피/돈/일상과 엮을 소재가 있을 때
- [ ] 시즌 이슈 (수능, 명절, 연말, 월드컵 등)
- [ ] 밈·유행어가 막 퍼지기 시작할 때 (정점 지나면 효과 급감 → **발견 후 1주 안에 업로드**)

## 실행 순서

### STEP 1. 소재 고르기 (30분)

- [ ] 이슈 이름이 그대로 훅이 되는가? (예: "로또 1등도 출근합니다")
- [ ] 직원이 **실제로 해볼 수 있는 행동**이 있는가? (명당 가서 로또 사기)
- [ ] 범표 캐릭터·티셔츠·로고가 자연스럽게 노출되는가?
- [ ] 저작권: 드라마 영상·음원 직접 사용 X, 제목·설정만 차용

### STEP 2. 체험 영상 촬영·편집 (반나절)

- [ ] 30~45초, 첫 2초에 웃긴 장면/궁금증 자막 ("나 왜 뛰지?")
- [ ] 커피 설명은 최소화 — 재미 우선
- [ ] **마지막 3초: 이벤트·혜택 안내 자막 + 어디서 사는지** (1회차에서 빠졌던 부분)
- [ ] 캡션: 이슈에 대한 공감 이야기 + 이벤트 한 줄

### STEP 3. 오가닉 업로드 → 24시간 관찰

- [ ] 24시간 지표가 평소 릴스 평균의 3배 이상이면 광고 집행 (1회차: 오가닉만 약 1.4만 조회)
- [ ] 댓글 응대 (재미있는 댓글엔 재치 있게)

### STEP 4. 광고 3일 부스트

- [ ] 목표: 웹사이트 방문 (1회차 도달 대비 방문 14.4%)
- [ ] 착지: **신규 방문자용** — 소용량(드립백·500g) + 이벤트 안내 페이지
- [ ] 예산·방문당 비용 기록

### STEP 5. 혜택·메시지 (선택)

이벤트를 붙일 경우 1회차 교훈 반영:

- [ ] 문턱 낮추기 or 단계형 ("구매 고객 전원 1장, 1kg 이상 3장")
- [ ] 기간 3일 이상 + 주말 포함
- [ ] 경품 관련 규정 사전 확인

### STEP 6. 측정 (D+7)

- [ ] 조회·도달·공유·저장·**팔로우** (이 루틴의 핵심 지표)
- [ ] 광고: 방문수, 방문당 비용
- [ ] 매장 신규 고객 수 — **"어떻게 알고 오셨어요?" 체크 필수**
- [ ] 이벤트 기간 판매 (평소 같은 기간과 비교)
- [ ] **브랜드 검색**: 스토어 검색어 "범표원두" 일별 방문을 업로드 전 7일 vs 후 7일로 비교 — 신규 고객이 이름을 검색해 들어왔는지 보는 핵심 지표

## 성공 기준

| 지표 | 성공 |
|---|---|
| 릴스 조회 | 평소 평균의 10배 이상 (1회차 20,022) |
| 공유 + 저장 | 30 이상 (1회차 32) |
| 팔로우 증가 | 10명 이상 (1회차 13) |
| 광고 도달 대비 웹사이트 방문 | 10% 이상 (1회차 14.4%) |
| 매장 신규 방문 | 릴스 보고 왔다는 고객 확인 |
| "범표원두" 검색 방문 | 평소(하루 약 21) 대비 1.5배 이상 |
| 캠페인 달 신규 주문고객 | 평소 월 160명(6월 제외 평균) 대비 증가 — 6월(253명) 수준이면 대성공 |

## R01과 언제 무엇을 쓰나

| | R01 외부 인정 소식 | R02 화제 이슈 편승 |
|---|---|---|
| 잘 되는 것 | **기존 고객 구매** (30개입 주말 12건) | **신규 도달·방문** (조회 2만, 팔로우 13) |
| 메시지 성격 | "우리 브랜드 자랑스러운 소식" | "재미있는 이벤트" |
| 혜택 | 기념 쿠폰 | 경품 (가벼운 조건이어야 함) |
| 핵심 지표 | 읽음·클릭·대용량 판매 | 조회·공유·팔로우·신규 방문 |
