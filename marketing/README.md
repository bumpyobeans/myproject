# 범표원두 마케팅 운영기획 진행룰

> 목적: 진행했던 캠페인 중 **반응이 좋았던 사례를 기록 → 패턴을 뽑아 → 반복 가능한 루틴(플레이북)으로 만든다.**
> 누가 맡아도 같은 순서·같은 품질로 다시 돌릴 수 있게 하는 것이 목표.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `cases/` | 실행한 캠페인 사례 기록 (1건 = 1파일, `YYYY-MM_주제.md`) |
| `playbook/` | 사례에서 뽑아낸 반복 루틴 (언제·무엇을·어떤 순서로) |
| `templates/` | 사례 기록 양식, 실행 체크리스트 |

## 기본 룰 5가지

1. **모든 캠페인은 사례로 남긴다.** 종료 후 7일 안에 `templates/case-template.md`로 기록. 반응이 나빴던 것도 남긴다 (안 되는 패턴도 자산).
2. **숫자로 판단한다.** "반응 좋았다"는 감이 아니라 지표로 적는다. 채널별 기준선(평소 평균) 대비 몇 배였는지 같이 적는다.
3. **2번 통하면 루틴으로 올린다.** 같은 패턴이 2회 이상 기준선을 넘으면 `playbook/`에 루틴으로 등록. 1회 성공은 "후보"로 표시.
4. **루틴은 체크리스트로 쓴다.** 설명이 아니라 실행 순서 + 담당 + 소요시간 + 완료 기준.
5. **월 1회 회고.** 루틴별 최근 성과를 보고 유지 / 수정 / 폐기를 결정하고 README의 루틴 목록을 갱신.

## 사례 → 루틴 승격 흐름

```
캠페인 실행 → 사례 기록(cases/) → 성공 요인 3줄 정리
   → 같은 패턴 2회 이상 성공? ── 아니오 → "후보"로 유지
                              └─ 예 → playbook/ 루틴 등록 → 다음 캠페인부터 체크리스트로 실행
```
