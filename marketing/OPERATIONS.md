## 3. 4주 순환 주간 행사

매주 무엇을 할지 고민하지 않도록 **4주를 한 바퀴로 돌린다.** 해당 루틴 문서의 체크리스트대로 실행.

| 주차 | 행사 유형 | 목표 | 루틴 | 예시 |
|---|---|---|---|---|
| 1주 | **핫딜** | 신규 고객 | [R03](playbook/R03_hotdeal-new-customers.md) | 범표라떼·드립백 주간 특가 |
| 2주 | **자랑 소식 / 고객 리뷰** | 기존 고객 구매 | [R01](playbook/R01_external-proof-multichannel.md) | 올리브영 리뷰, 신규 입점, 좋은 후기 소개 |
| 3주 | **화제 이슈 편승** | 도달·팔로우 | [R02](playbook/R02_trend-ride-reels-boost.md) | 드라마·시즌 이슈 체험 릴스 |
| 4주 | **단골 감사** | 재구매·이탈 방지 | (P6) | 라운지 멤버 전용 쿠폰, 1주차 핫딜 구매자 재구매 메시지 |

- 큰 시즌(명절·연말)이 있는 주는 순환보다 시즌 행사 우선 → [시즌 캘린더](#5-시즌-캘린더-202610--202702)
- 기본 타깃: **여성 30~40대** (결제 60%·매출 62%). 톤·혜택은 이 고객 기준.

## 4. 광고비 월 100만원 운영 룰

| 구분 | 금액 | 용도 |
|---|---|---|
| 부스트 | 60만원 (주 15만원) | 매주 반응 좋은 릴스 1개를 3일 광고 (R02 STEP 4) |
| 상시 | 30만원 | 여성 30~40대 대상 웹사이트 방문 광고 (대표 상품·드립백) |
| 테스트 | 10만원 | 새 소재·새 타깃 시험 |

- 목표: 웹사이트 방문 (참고: 범또 광고 도달 대비 방문 14.4%)
- 착지: 신규는 소용량(드립백·500g)·행사 페이지
- **첫 달은 기준 잡기**: 방문 1회당 비용을 기록해 둘째 달부터 목표치로 사용

> 전체 대시보드(노출 13,731 / 클릭 244)와 차이 나는 노출 약 6,600·클릭 약 150은 다른 캠페인 몫 → 나머지 캠페인도 같은 표로 기록.

**룰 1. 브랜드 키워드는 "방어" 광고 — 끄지 않는다.**
- 이유: "범표원두"를 검색하면 입점사(쿠팡·29CM 등)가 광고를 걸어 **우리 공식 스토어가 밀려 안 보였음.** 검색 판매 100%가 브랜드 검색(P5)이라, 여기서 1위를 뺏기면 우리 고객이 입점사에서 산다.
- 판단 기준은 전환이 아니라 **"범표원두 검색 시 공식 스토어 광고가 맨 위에 나오는가"** + 비용. 현재 클릭당 55원, 주 3,190원 → 매우 싼 보험.
- 담당자: **매주 월요일 "범표원두" 직접 검색 → 공식 스토어가 1위인지 캡처**해 주간 보고서에 첨부. 밀리면 입찰가를 올린다 (단독 결정 가능 상한: 클릭당 ____원).
- 검색 결과에서 입점사는 가격·혜택으로 경쟁 중 (쿠팡 로켓배송·첫구매 할인, 29CM 29% 혜택). → 공식 스토어 광고 문구·확장소재에 **"공식몰에서만" 혜택**(라운지 쿠폰, 선물포장, 신선 로스팅일 등)을 넣는다.

**룰 2. 일반 키워드는 "구매"로 판단한다.**
- "동결건조커피/파우더커피": 클릭률 2.0%로 반응은 좋지만 클릭당 309원(브랜드의 약 6배), 비용의 75%를 씀. 최근 30일 스토어 검색 "동결건조 커피"는 방문 25·판매 0 → **구매 전환 확인이 1순위.**
- 광고그룹 표 "열 맞춤 설정"에서 **전환수·전환매출·광고수익률(ROAS)** 열을 켜고 그룹별로 기록.
- 2주간 구매 0이면 입찰가 낮추거나 키워드 교체 (예: 드립백커피, 커피선물세트, 원두선물).
- "카페라떼_랜": 1주 노출 69 → 거의 노출 안 됨. 입찰가·키워드 점검 (스토어 검색 "범표라떼" 19방문·판매 0과 함께 확인).

**룰 3. 전환 = 주문인지 확인.** 네이버 전환은 장바구니 등도 포함될 수 있음 → 전환 유형 중 "구매"만 따로 본다.

**플레이스(지역소상공인광고) 소재 바꾸는 법** — 확인 완료 (2026-10)

문구·사진은 광고센터가 아니라 **스마트플레이스의 "지역소상공인광고 소재 등록하기"** 화면에서 바꾼다.

1. 스마트플레이스 로그인 → 구리갈매점 선택 → **지역소상공인광고** 메뉴 → "소재 등록하기" 화면
2. **문구 2줄** 입력 — 줄당 **13자**(띄어쓰기 포함) 제한
3. 사진 오른쪽 위 **"변경"**으로 사진 교체
4. **지역명 노출**: 업체명에 이미 "구리갈매점"이 있으므로 네이버 안내대로 **"지역명 노출 안함"** 권장 (지금 "시군구 노출"이라 "구리시 범표원두 구리갈매점"으로 제목이 두 줄로 넘어감)
5. **유효기간**: 기간 있는 혜택·이벤트를 문구에 넣으면 반드시 "유효기간 설정" (끝난 혜택이 계속 노출되면 고객 혼란)
6. 저장 → 약 2시간 뒤 광고센터 "소재 미리보기"로 확인 → 바꾼 날짜를 주간 보고서에 기록
7. 메뉴·가격·대표 메뉴 순서는 스마트플레이스 → 업체정보에서 수정

참고: 지역소상공인광고는 **검색 결과가 아니라 네이버 뉴스·블로그 등 콘텐츠 화면**에 동네 사람에게 노출되는 광고 → 클릭률이 검색광고보다 낮은 게 정상. 길찾기·저장·방문으로 판단.

- 원인: 네이버는 **플레이스 업체의 사업자 정보로 만든 계정**이 직접 광고하는 것이 원칙. 계정 업체명·사업자와 플레이스 업체명·사업자가 맞지 않으면 보류.
- 플레이스 이름을 "별내하나로마트점 → 별내점"으로 바꾸면서 애드부스트 계정의 업체명과도 달라짐.
- 해결 순서:
  1. 스마트플레이스 별내점에 등록된 **사업자등록번호** 확인 ↔ 광고 계정(광고센터 → 정보관리 → 사업자 정보)의 사업자등록번호 비교
  2. **같으면**: 광고센터 → 도구 → 비즈채널 → 별내점 **재검토 요청** + 별내점 주소가 나온 사업자등록증(지점 등록) 첨부
  3. **다르면** (별내점이 별도 사업자): 별내점 사업자 정보로 계정을 만들어 광고 (담당자에게 권한 공유)
  4. 막히면 네이버 광고 고객센터에 계정번호·비즈채널명 알려주고 문의
- **확인된 구조 (2026-10)**: 법인. 구리갈매점 = 본점, 별내점 = 같은 법인의 지점. **확인: 법인등록번호 같음, 사업자등록번호 다름** → 본점 번호로 만든 범표_2026 계정과 별내점 플레이스가 "관계 미확인"으로 걸린 것으로 판단.
  - 애드부스트 계정(2628391)이 **별내점 사업자번호**로 만들어졌다면: 이름만 다른 것 → 계정 업체명을 "범표원두 별내점"으로 맞추고(광고센터 정보관리 또는 고객센터) 재검토 요청이 가장 빠름.
  - ~~범표_2026에서 하려면~~ → **불가 확인**: 범표_2026은 범표원두팩토리(개인) 사업자라 법인 지점과 관계 증명이 안 됨. 별내점은 별내점(법인 지점) 계정에서만.  비즈채널 재검토 요청 + **별내점 사업자등록증**(법인명·법인등록번호가 본점과 같음을 보여줌) + **본점 사업자등록증** 또는 법인등기부등본 첨부.
- **계정 원칙 (변경)**: 네이버 원칙이 "업체 사업자 정보로 만든 계정이 직접 광고"이므로 **사업자번호 1개 = 광고 계정 1개**로 운영. 본점 계정(쇼핑검색·브랜드·구리갈매점 플레이스) / 별내점 계정(별내점 플레이스). 프랜차이즈 지점도 같은 방식으로 늘린다.

**광고 계정 5개 정리 → [ad-accounts.md](ad-accounts.md)** (계정별 역할·점검표·정리 순서)

- **"애드부스트 플레이스" 계정 = 스마트플레이스 → 마케팅 → "플레이스광고-ADVoost"를 신청하면 업체별로 자동 생성되는 계정.** ADVoost는 네이버 AI가 알아서 노출하는 플레이스(검색·지도) 광고. 소재에 스마트플레이스 **쿠폰·할인정보가 노출**되므로 VIP카드 혜택을 스마트플레이스 → 마케팅 → 쿠폰에 등록해 둔다.

### 네이버 플레이스 검색광고 (도입 제안)

지역소상공인광고(뉴스·블로그 화면, 동네 사람에게 **알리기**)와 다르게, 플레이스 검색광고는 **"갈매동 카페" 같은 검색을 한 사람**(지금 갈 곳을 찾는 사람)에게 지도·플레이스 상단에 노출된다. 매장 방문으로 가장 직접 이어지는 광고.

- 시작 전: 스마트플레이스 정비 (대표 사진·메뉴·영업시간·리뷰 답글) — 광고를 눌러 도착하는 곳이 플레이스 페이지
- 예산: 하루 5,000원 (월 약 15만원)으로 2주 테스트
- 키워드 예시: 갈매동카페, 갈매역카페, 구리카페, 구리로스터리, 갈매라떼, 구리 원두 (별내점 오픈 시 별내 키워드 별도 캠페인)
- 판단 (2주 후): 길찾기·전화·저장 1건당 비용, "어떻게 알고 오셨어요?" 응답

**광고비 배분 (100만원 기준, 제안)**: 네이버 쇼핑검색 35 / 인스타 부스트 35 / 네이버 플레이스(검색+지역) 15 / 인스타 상시 10 / 테스트 5 (만원). 2주마다 1건당 비용(구매·길찾기)이 낮은 쪽으로 옮긴다.
