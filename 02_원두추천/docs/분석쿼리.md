# 상담 기록 분석 쿼리 모음

Supabase 대시보드 → **SQL Editor** → New query 에 붙여넣고 Run.
결과는 표로 나오고, 오른쪽 위 **Export** 로 CSV 저장 가능.

표 구조는 `docs/supabase.sql` 참고.
- `sessions` = 상담 시작 1건 (유입 경로·기기·방문자번호)
- `events` = 행동 1건 (`type`: start / answer / result / shop_click / share / restart / chip)

---

## 1. 유입 경로별 깔때기 (방문 → 결과 도달 → 상품 클릭)

"어떤 경로로 온 사람이 실제로 상품까지 가는가"

```sql
select
  coalesce(s.src, '(없음)')                                   as 경로,
  count(distinct s.id)                                        as 방문,
  count(distinct e_r.session_id)                              as 결과도달,
  count(distinct e_c.session_id)                              as 상품클릭,
  round(100.0 * count(distinct e_c.session_id) / nullif(count(distinct s.id), 0), 1) as "클릭률(%)"
from sessions s
left join events e_r on e_r.session_id = s.id and e_r.type = 'result'
left join events e_c on e_c.session_id = s.id and e_c.type = 'shop_click'
group by 1
order by 방문 desc;
```

경로 값은 링크 뒤에 붙인 `?src=...` 입니다.
- 카톡 채널·인스타·스마트스토어 배너에 각각 `?src=kakao` `?src=insta` `?src=store` 를 붙여 배포
- 친구 공유 버튼은 자동으로 `?src=friend`
- 아무것도 없으면 `(없음)` — 직접 주소 입력이거나 파라미터 없는 링크

## 2. 재도전: 한 사람이 몇 번 하는가

```sql
select
  세션수 as "상담 횟수",
  count(*) as "사람 수"
from (
  select visitor_id, count(*) as 세션수
  from sessions
  group by visitor_id
) t
group by 1
order by 1;
```

"다시 확인하기" 버튼 클릭 자체만 세려면:
```sql
select count(*) as "다시확인 클릭", count(distinct visitor_id) as "누른 사람"
from events where type = 'restart';
```

## 3. 친구 공유율

결과까지 간 사람 중 공유 버튼을 누른 비율.

```sql
with reached as (
  select distinct session_id from events where type = 'result'
),
shared as (
  select distinct session_id from events where type = 'share' and (payload->>'ok') = 'true'
)
select
  (select count(*) from reached)                        as 결과도달,
  (select count(*) from shared)                         as 공유,
  round(100.0 * (select count(*) from shared) / nullif((select count(*) from reached), 0), 1) as "공유율(%)";
```

공유 방식별(휴대폰 공유창 / PC 복사 / 텍스트 표시):
```sql
select payload->>'method' as 방식, payload->>'ok' as 성공, count(*)
from events where type = 'share'
group by 1, 2 order by 3 desc;
```

친구 링크로 실제로 들어온 사람: 1번 쿼리에서 `경로 = friend` 행.

## 4. 어떤 상품이 추천·클릭되는가

추천된 "오늘의 추천" TOP:
```sql
select payload->>'chosen_name' as 상품, count(*) as 추천횟수
from events where type = 'result'
group by 1 order by 2 desc limit 20;
```

클릭된 상품 TOP (위치별):
```sql
select payload->>'name' as 상품, payload->>'position' as 위치, count(*) as 클릭
from events where type = 'shop_click'
group by 1, 2 order by 3 desc limit 20;
```

위치 뜻: `main` = 오늘의 추천, `new` = 새로운 커피 경험, `sample` = 처음이라 부담되시면

## 5. 어떤 답을 많이 고르는가

```sql
select payload->>'q' as 질문, payload->>'value' as 답, count(*) as 횟수
from events where type = 'answer'
group by 1, 2 order by 1, 3 desc;
```

질문 뜻: q1 음용방식 / q_amount 원두용량 / q_milk 우유 / q_latte 라떼종류 / q2 맛 / q3 부담맛 / q4 카페인 / q5 (잘모름 후속)

특정 조합 (예: 선물 + 디카페인) 세기:
```sql
select count(*)
from events
where type = 'result'
  and payload->'answers'->>'q1' = '선물'
  and payload->'answers'->>'q4' = '디카페인';
```

## 6. 일별 방문 (최근 14일)

```sql
select
  (created_at at time zone 'Asia/Seoul')::date as 날짜,
  count(*) as 방문,
  count(distinct visitor_id) as 사람,
  sum(case when device = 'mobile' then 1 else 0 end) as 모바일
from sessions
where created_at > now() - interval '14 days'
group by 1 order by 1 desc;
```

---

## 7. 한 사람의 여정 따라가기 (문제 확인용)

```sql
select e.created_at at time zone 'Asia/Seoul' as 시각, e.type, e.payload
from events e
where e.session_id = '여기에-세션-id'
order by e.created_at;
```
세션 id 는 `select id, created_at from sessions order by created_at desc limit 20;` 로 찾음.

---

## 참고

- 시각은 UTC 로 저장됨. 한국 시간으로 보려면 `at time zone 'Asia/Seoul'`.
- 무료 플랜은 1주일 정도 접속이 없으면 프로젝트가 잠들어 기록이 멈춤. 대시보드에 가끔 들어가면 안 잠듦.
- 개인정보 없음. `visitor_id` 는 브라우저가 만든 무작위 값.
