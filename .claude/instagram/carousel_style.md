# 범표원두 기본 캐러셀 스타일 — "깔끔 + 사진"

2026-11-06 김현정이 지정한 기본 스타일. 참고 원본은 @bmoc79 "RYAN79 상권 리포트" 캐러셀.
**앞으로 캐러셀은 따로 말이 없으면 이 스타일로 만든다.** 구현은 `carousel/carousel_kit.py`.

## 기본 규격

- 1080×1350 (4:5). 글꼴은 Pretendard (`fonts/`, SIL OFL).
- 배경 크림색 `#F6F1EB`, 글자 거의 검정 `#161616`, 보조 글자 회색.
- 포인트: 헤더의 작은 네모는 범표 갈색 `#AF8058`. 강조 문장은 노란 형광펜 `#FBE3A0`.
- 진한 면(커버 하단 바, 어두운 장)은 범표 진한 색 `#1C2D2F`.

## 장 종류

| 종류 | 생김새 | 함수 |
| --- | --- | --- |
| **커버** | 사진 꽉 채움 + 어둡게, 왼쪽 위 흰 테두리 태그("○○ 이야기 · No.01"), 아주 큰 흰 굵은 제목 3줄(첫 단어 밑줄), 부제 1줄, 맨 아래 진한 바(왼쪽 @계정, 오른쪽 소개) | `cover()` |
| **숫자** | 위에 둥근 사진 카드, "이 ○○의 숫자" 제목, 흰 카드 2×2(큰 숫자 + 설명 2줄) | `stats()` |
| **항목** | 둥근 사진 카드(위 또는 아래, 번갈아), 얇고 큰 번호 "01" + 굵은 제목, 본문 2~4줄(핵심어 **굵게**), 마지막 한 줄 노란 형광펜 | `item()` |
| **어두운 항목** | 항목과 같고 배경만 진한 색, 흰 테두리 태그("○○의 실전"), 형광펜 대신 밑줄 | `item(dark=True)` |
| **한 줄** | 사진 없음. 작은 머리말, 아주 큰 굵은 문장 3줄, 출처 줄, 가로선, 공식 한 줄("A + B = C"), 맨 아래 진한 바("저장해두고 ○○ 때 꺼내 보세요") | `quote()` |

## 모든 장 공통

- 왼쪽 위: `■ 범표원두 ○○ 리포트` (네모는 갈색)
- 오른쪽 위: `02 / 10` 장 번호
- 왼쪽 아래: `@bumpyobeans`, 오른쪽 아래: `옆으로 넘기기 →` (커버·한 줄 장 제외)
- 사진 카드는 모서리 둥글게, 남의 사진이면 오른쪽 아래에 출처 표기
- 본문은 존댓말 설명체, 문장 짧게. 각 항목은 형광펜 한 줄로 끝맺는다.

## 순서 틀 (10장)

1 커버 → 2 숫자 → 3~8 항목(사진 위/아래 번갈아) → 9 한 줄 → 10 어두운 항목(추천·주문 안내)
