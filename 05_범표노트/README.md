# 범표원두 노트 — 글 쓰는 법

1. `src/posts/` 폴더를 엽니다.
2. `_템플릿.md` 파일을 복사해서 새 이름으로 저장합니다. (예: `2026-03-01-신메뉴-이야기.md`)
3. 파일 이름 규칙: `날짜-영문슬러그.md` (예: `2026-03-01-new-menu.md`)
4. 맨 위 `---` 사이 부분(제목, 날짜, 카테고리 등)을 채웁니다. 카테고리는 정해진 5개 중 하나만 씁니다.
5. `public: false` 로 쓰면 그 글은 사이트에 안 보입니다. 비워두면 자동 공개입니다.
6. `---` 아래부터 본문을 씁니다. 빈 줄로 문단을 나눕니다.
7. 저장 후 `npm run dev` 로 미리 확인, `npm run build` 로 실제 사이트 파일을 만듭니다.
8. 파일명이 `_`로 시작하면(`_템플릿.md`처럼) 절대 글로 나오지 않습니다.
