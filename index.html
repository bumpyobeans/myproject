어떤 자료를 받으면 되나요?

CUBE_CENTER (1호기)
  • 상품 분석 화면 → 날짜를 하루로 두고 조회 → 엑셀로 저장
  • 시간대별 분석 → 같은 날짜로 엑셀 저장 (피크·한산 시간 분석용)
  • 일 매출 현황 → 한 달 단위로 저장하면 일별 추이와 객단가가 나옵니다
O2POS Web (2호기)
  • 점포별 상품별 매출현황 → 날짜를 하루로 두고 조회 → EXCEL
  • 시간대별 매출 화면이 있으면 같은 날짜로 EXCEL 저장
  • 일별 매출 화면이 있으면 한 달 단위로 EXCEL 저장

상품 자료는 하루 단위로 받는 것이 가장 좋습니다. 여러 날을 한 파일로 받으면 그 기간 전체를 선택했을 때만 집계되고, 일별 차트에는 날짜별로 똑같이 나눠 표시됩니다.

정말 삭제할까요?
매출은 할인을 뺀 실매출(부가세 포함) 기준입니다. CUBE는 ‘매출 금액’, O2POS는 ‘총매출 − 할인금액’으로 맞춰 계산합니다.
