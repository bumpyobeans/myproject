# 범표나들이 인증 사진첩

스탬프 카드 뒷면의 QR을 찍은 손님이 **인스타그램 게시물 링크**를 보내면, 그 게시물들이 한곳에 모여 **사진첩**이 됩니다.
서버 없이 구글 스프레드시트와 Apps Script만으로 돌아가며, 무료입니다.

| 주소 | 용도 |
|---|---|
| `…/exec` | 인증 제출 페이지 (QR 코드에 넣을 주소) |
| `…/exec?page=gallery` | 인증 사진첩 (매장 POS 옆 태블릿, 인스타 프로필 링크 등에 활용) |

## 동작 방식

1. 손님이 완성된 스탬프 카드 사진을 해시태그(`#10월의범표나들이` 등)와 함께 인스타그램에 올립니다.
2. 카드 뒷면 QR → 제출 페이지에서 게시물 링크, 닉네임, 연락처 뒷자리 4자리, 방문 매장(3곳 이상)을 입력합니다.
3. 입력한 내용은 스프레드시트의 `인증` 시트에 한 줄씩 쌓입니다. 같은 게시물 링크는 중복으로 접수되지 않습니다.
4. 사진첩 페이지는 인스타그램 공식 임베드로 게시물을 최신순으로 보여주고, 매장별로 걸러 볼 수 있습니다. 연락처는 공개되지 않습니다.

## 설치 (약 10분)

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다. 예: `범표나들이 인증`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 이 폴더의 파일 4개를 같은 이름으로 만들어 내용을 붙여넣습니다.
   - `Code.gs`: 기본으로 있는 `코드.gs`에 덮어쓰기
   - `Index.html`, `Gallery.html`, `Styles.html`: `+` → **HTML**로 만들 때 확장자를 뺀 `Index`, `Gallery`, `Styles`로 입력
4. 저장한 뒤 **배포 → 새 배포 → 유형: 웹 앱**을 고릅니다.
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. 권한 승인 화면이 나오면 승인합니다. "확인되지 않은 앱" 경고가 뜨면 **고급 → 이동**을 누르세요.
6. 발급된 `https://script.google.com/macros/s/…/exec` 주소로 **QR 코드**를 만들어 카드 뒷면 2번 자리에 넣습니다.
7. 스프레드시트를 새로고침하면 `범표나들이` 메뉴가 생깁니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 QR 주소가 그대로 유지됩니다.

## 운영

- **게시물 숨기기**: `인증` 시트에서 해당 줄의 `노출` 열을 `N`으로 바꾸면 사진첩에서 빠집니다.
- **사전 검수제로 바꾸기**: `Code.gs`의 `AUTO_APPROVE`를 `false`로 바꾸세요. 새 제출은 `N`으로 들어오고, 확인한 줄만 `Y`로 바꾸면 노출됩니다.
- **추가 선물 추첨**: 스프레드시트 메뉴 **범표나들이 → 추가 선물 당첨자 추첨**을 누르면, 노출(`Y`) 중인 인증 가운데 무작위로 뽑아 `당첨자` 시트에 기록합니다. 매장에서는 닉네임과 연락처 뒷자리로 당첨자를 확인하면 됩니다.
- 매장 이름과 해시태그는 `Code.gs` 위쪽의 `CONFIG`에서 바꿀 수 있습니다.

## 참고

- 사진첩에는 **공개 계정**의 게시물만 보입니다. 비공개이거나 삭제된 게시물은 "인스타그램에서 보기" 링크로만 표시됩니다.
- 게시물, 릴스 링크 모두 받을 수 있으며 `?igsh=…` 같은 공유 꼬리표는 자동으로 정리됩니다.
