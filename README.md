# 카페 키오스크 매출노트

키오스크 2대의 판매내역(CSV)을 불러와 매출·메뉴·시간대 데이터를 한 화면에서 보고, 매출을 올릴 아이디어를 자동으로 뽑아 주는 대시보드입니다.
설치할 것 없이 `index.html` 파일 하나를 브라우저로 열면 됩니다.

## 볼 수 있는 것

| 화면 | 내용 |
|---|---|
| 핵심 지표 | 총매출, 주문 건수, 객단가, 하루 평균 매출 (이전 같은 기간 대비 증감) |
| 매출 상승 아이디어 | 피크 시간 대응, 한산 시간 프로모션, 디저트 동반 구매, 세트 조합, 키오스크 쏠림, 약한 요일, 메뉴 정리 후보 |
| 일별 매출 | 키오스크별 누적 막대 |
| 키오스크 비교 | 매출 비중, 주문 수, 객단가, 바쁜 시간, 최다 판매 메뉴 |
| 시간대별 평균 | 하루 기준 시간별 매출 / 주문 수 |
| 요일 × 시간 지도 | 요일·시간별 평균 매출 히트맵 |
| 메뉴별 판매 순위 | 수량, 매출, 비중, 키오스크별 비율, 잘 팔리는 시간, ABC 등급 |
| 시간대별 인기 메뉴 | 아침 / 점심 / 오후 / 저녁 Top 5 |
| 함께 팔리는 조합 | 같은 주문에 자주 담기는 메뉴 쌍 (세트 후보) |

위쪽에서 기간(7일 / 30일 / 전체 / 직접 선택)과 키오스크(전체 / 1호기 / 2호기)를 고를 수 있습니다.

## 데이터 넣는 방법

1. 키오스크 관리 페이지(또는 POS 사이트)에서 **판매내역을 엑셀/CSV로 내려받습니다.** 1호기, 2호기를 따로 받아도 되고 한 파일이어도 됩니다.
2. 엑셀 파일이면 “다른 이름으로 저장 → CSV”로 바꿉니다. (UTF-8, EUC-KR 모두 자동 인식)
3. 화면 맨 아래 **데이터 관리**에 파일을 끌어다 놓습니다.
4. 날짜·메뉴·수량·금액 열이 자동으로 연결됩니다. 틀린 칸만 고치고, 어느 키오스크 파일인지 고른 뒤 **불러오기**.

필요한 열은 최소 **날짜(+시간), 메뉴명, 금액(또는 단가)** 입니다. 주문번호가 있으면 객단가와 “함께 팔리는 조합”이 정확해집니다.

```csv
주문번호,결제일시,메뉴명,수량,금액
A-0001,2026-09-01 08:12:33,아메리카노,2,8000
A-0001,2026-09-01 08:12:33,소금빵,1,3500
```

- 같은 키오스크·같은 날짜를 다시 불러오면 기존 데이터를 **교체**하므로 중복되지 않습니다. 매주 최신 파일을 그냥 다시 올리면 됩니다.
- “합계/소계” 줄은 자동으로 건너뜁니다. 금액이 음수(취소·환불)면 매출에서 빠집니다.
- 메뉴 이름에 빵·케이크·쿠키 등이 들어가면 디저트로 분류합니다. 파일에 분류 열이 있으면 그것을 씁니다.
- 데이터는 **그 브라우저에만** 저장됩니다. 원본 CSV는 따로 보관해 두세요.

처음 열면 예시 데이터(가상의 8주 판매 기록)가 보입니다. 화면 오른쪽 위에 “예시 데이터”라고 표시되며, 내 파일을 불러오면 바로 바뀝니다.

## 매출 기획에 쓰는 순서 (추천)

1. **주 1회** 두 키오스크 CSV를 올린다.
2. **요일 × 시간 지도**에서 비어 있는 시간대를 찾고 → 그 시간 한정 프로모션을 기획한다.
3. **함께 팔리는 조합** 1~2위를 세트로 묶어 키오스크 첫 화면에 올린다.
4. **메뉴 순위의 C등급**은 첫 화면에서 빼거나 계절 메뉴로 교체한다.
5. 2~4주 뒤 같은 기간을 비교해(핵심 지표의 ▲▼) 효과를 확인한다.
