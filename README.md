# 가맹점 키오스크 월별 매출 관리

가맹점 키오스크에서 받은 매출 엑셀을 모아 **월별 리포트 엑셀**을 만듭니다.

## 설치

```bash
pip install -r requirements.txt
```

## 사용법

1. 받은 매출 파일(`.xlsx`, `.xls`, `.csv`)을 `data/raw/` 아래에 넣습니다. 월별 폴더로 나눠 두면 관리하기 편합니다.
   ```
   data/raw/2026-09/본사통합.xlsx
   data/raw/2026-09/부산점.xlsx     ← 가맹점 컬럼이 없으면 파일명이 가맹점명
   ```
2. 리포트를 만듭니다.
   ```bash
   python -m kiosk_sales months            # 들어있는 월 목록과 매출 합계
   python -m kiosk_sales report 2026-09    # 해당 월 리포트
   python -m kiosk_sales report            # 가장 최근 월 리포트
   ```
3. `reports/2026-09_월별매출리포트.xlsx` 가 생성됩니다.

## 리포트 구성

| 시트 | 내용 |
|---|---|
| 가맹점별 요약 | 순위, 매출합계, 거래건수, 객단가, 영업일수, 일평균매출, 전월대비 (로열티율 설정 시 로열티) |
| 일별 매출 | 일자 × 가맹점 매출표 |
| 메뉴별 | 메뉴별 매출·수량·비중 (메뉴 컬럼이 있을 때) |
| 결제수단별 | 결제수단별 매출·비중 (결제수단 컬럼이 있을 때) |
| 월별 추이 | 가맹점 × 월 매출 추이 |

## 엑셀 컬럼 맞추기

`config.json` 의 `columns` 에 실제 엑셀 컬럼명을 추가하면 됩니다. 필수는 **일자(date)**, **금액(amount)** 이고, 가맹점(store)이 없으면 파일명을 가맹점명으로 씁니다.
주문번호(order_id)가 있으면 거래건수를 주문 단위로 세고, 없으면 행 수로 셉니다.
가맹점 로열티를 계산하려면 `royalty_rate` 를 설정하세요 (예: 3% → `0.03`).

## 참고

- `data/raw/`, `reports/` 의 실제 매출 파일은 `.gitignore` 로 저장소에 올라가지 않습니다.
- 같은 파일을 두 번 넣어도 완전히 같은 행은 한 번만 집계됩니다.
- 테스트: `python -m pytest`
