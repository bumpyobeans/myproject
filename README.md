# 가맹점 키오스크 월별 매출 관리

가맹점 키오스크에서 내려받은 **상품별 매출 엑셀**(월 단위)을 가맹점별로 모아, 가맹점별 월 리포트와 전체 가맹점 요약을 만듭니다.

## 설치

```bash
pip install -r requirements.txt
```

## 사용법

```bash
# 1. 매출 엑셀 등록 — 엑셀 제목의 매장명·기간을 읽어 data/raw/<가맹점>/<YYYY-MM>.xlsx 로 저장
python -m kiosk_sales add 별내점_9월.xlsx
python -m kiosk_sales add 신규매장.xlsx --store 신규점    # config.json 에 없는 매장은 가맹점명 지정

# 2. 등록 현황 (가맹점 × 월 매출)
python -m kiosk_sales list

# 3. 리포트 생성
python -m kiosk_sales report 2026-09                 # 해당 월 전 가맹점 + 전체 요약
python -m kiosk_sales report 2026-09 --store 별내점   # 특정 가맹점만
python -m kiosk_sales report                         # 가장 최근 월
```

## 폴더 구조

```
data/raw/별내점/2026-09.xlsx              ← 원본 (가맹점별 폴더, 월별 파일)
reports/별내점/별내점_2026-09_매출리포트.xlsx
reports/전체/2026-09_가맹점별요약.xlsx
```

## 리포트 구성

**가맹점별 리포트** (`reports/<가맹점>/`)

| 시트 | 내용 |
|---|---|
| 요약 | 총매출, 판매수량, 판매 상품 수, 할인, 전월대비, 결제수단별(현금/카드/포인트/외상/기타) 금액·비중, 로열티 |
| 대분류별 | 대분류별 수량·매출·비중·전월대비 |
| 상품별 | 매출 순위, 상품코드, 수량, 매출, 비중, 전월 수량·매출·전월대비 |
| 월별 추이 | 월별 총매출·수량·전월대비와 대분류별 매출 |

**전체 요약** (`reports/전체/`): 가맹점별 매출 순위·전월대비·결제수단·로열티, 전체 대분류/상품별, 가맹점 × 월 추이

## 엑셀 양식

키오스크 관리자 페이지의 "상품별 매출" 내보내기 양식을 그대로 읽습니다.

- 1행 제목: `<매장명>의 2026-09-01 ~ 2026-09-30 상품별 매출` → 매장명과 월을 자동 인식
- 헤더: 번호 | 대분류 | 상품코드 | 상품명 | 판매수 | 결제 합계 | 현금 | 카드 | 포인트 | 외상 | 기타 | 할인 합계
- 상품 행 합계가 파일의 "합계" 행과 다르면 등록을 거부합니다.
- 같은 상품코드가 월 중 대분류·상품명이 바뀌어 여러 행으로 나오면 상품별 시트에서는 하나로 합칩니다.

## 가맹점 설정 (`config.json`)

```json
"stores": {
  "별내점": { "aliases": ["별내농업협동조합 하나로마트"], "royalty_rate": 0.03 }
}
```

- `aliases`: 엑셀 제목에 찍히는 매장명. 등록해 두면 `add` 시 가맹점이 자동 판별됩니다.
- `royalty_rate`: 로열티율 (3% → `0.03`).

## 참고
